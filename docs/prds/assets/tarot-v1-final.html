390 × 844 ptThreeCardPick
09

Three-card pick

live

INTERACTIVE. Pick three times, one per position. Shuffle as often as you like between picks. "Start the spread over" resets.

The Reading type tweak above the artboard covers all four variants: Career, Relationship, Relationship · someone specific, and Social. Every deep reading in every area uses this same screen — only the question, the accent and the position labels change.

The named-person variant is the one that differs structurally: You / Them / The Connection instead of Situation / Action / Outcome.

The three slots show from the start, so the user always knows how many draws remain. The question stays on screen throughout — three rounds is long enough to forget what you asked.

Unlike the daily card, these picks GENUINELY determine the cards (§4.2.11). A placed card locks — same integrity rule as the daily no-redraw.

WATCH THIS ONE: three picks now sit between peak intent and the answer. spread_abandoned{area, picks_made} is the metric; if it clusters at 1–2, a "draw all three for me" shortcut is the fix (§9).
